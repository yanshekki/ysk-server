## 1. 我們是誰

YSK Limited（香港）發布 YSK Server。聯絡：email@ysk.hk · https://ysk.hk/

本政策說明 YSK Limited 如何處理個人資料，並以香港法例第 486 章《個人資料（私隱）條例》（「私隱條例」）為框架。YSK Limited 僅就其實際收到的個人資料屬資料使用者。

## 2. 自行託管：我們看不到你的安裝

YSK Server 在你的機器上運行。在一般產品使用中，YSK Limited 不會收到遙測、當機報告、鏈上資料、電郵、檔案、面板憑證、驗證者金鑰或你主機的內容。使用本軟件無須 YSK Limited 雲端帳戶。

本政策不聲稱收集產品並未執行的資料。若日後版本加入可選遙測，將會載明，且預設關閉，除非你選擇加入。

## 3. 我們何時處理個人資料

僅在你選擇向我們提供時，我們才處理個人資料，包括：

- 發送至 email@ysk.hk 的支援或錯誤電郵（姓名、電郵地址、技術事實、log 或你附上的診斷貼文）。
- 就 YSK Limited 收費工作提出的商務查詢。
- 捐款或贊助往來。本軟件不含支付處理器。GitHub Sponsors、Linktree 及鏈上捐款屬第三方服務。
- 你在公開倉庫發布的 GitHub issue、pull request 及討論。

我們使用該等資料以回覆、改進本軟件、保存法律申索或會計所需紀錄，以及就你的請求作通訊。

## 4. 你面板上的資料

工作階段 cookie、語言偏好及面板使用的其他儲存，位於你所設定的來源（你的瀏覽器與你的面板通訊）。該處理屬你的處理。你是該主機的營運者，按事實可能屬私隱條例下的資料使用者，或在其他法律下屬你自身用戶的控制者。本政策並不使 YSK Limited 成為你客戶資料的控制者。

## 5. 你選擇的第三方

若你使用 GitHub、npm、Let's Encrypt、Docker 倉庫、DNS 供應商、區塊鏈網絡或類似服務，他們收到的資料受其政策規管。YSK Limited 並不控制該等服務。

## 6. 不出售個人資料

我們不出售個人資料。

## 7. 保留

支援及查詢電郵在處理請求、保存安全或濫用紀錄，以及履行法律責任所需期間內保留，其後刪除或以限制存取方式封存。公開 GitHub 內容按 GitHub 條款留在 GitHub。

## 8. 查閱及改正（私隱條例）

若我們持有你的個人資料，你可按私隱條例請求查閱及改正。請電郵 email@ysk.hk。我們或須核實你的身分。我們不設歐盟代表，不就我們無法看見的自行託管產品聲稱 GDPR 資料可攜流程，亦不在「我們不出售個人資料」的事實以外，聲稱具備 CCPA「請勿出售」機制。

## 9. 你發送資料的安全

我們對收到的支援電郵採取合理措施。任何電郵途徑均非絕對安全。請勿以電郵發送冷錢包金鑰、種子短語或生產環境密碼。

## 10. 兒童

本軟件面向 Linux 伺服器營運者，並非面向兒童。我們不會明知而向兒童索取個人資料。

## 11. 跨境轉移

電郵及 GitHub 可能在香港以外儲存或處理資料。你經該等渠道聯絡我們，即表示理解此事。

## 12. 修訂

我們可在倉庫及面板更新本政策。「最後更新日期」將隨之變更。你在該日期之後繼續使用本軟件，即視為接受更新後的政策，適用於我們其後處理的資料。
