# Legal documents

> Language: English | [中文](./README-ZH.md)

**YSK Limited** publishes YSK Server as free, open-source, self-hosted software. These documents protect YSK Limited and tell operators who is responsible for the machine.

They are **not** a substitute for advice from a solicitor admitted in Hong Kong. They do **not** make YSK Limited a SaaS data controller for an install that runs on a host you control.
