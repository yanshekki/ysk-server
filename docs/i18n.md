# Internationalization (i18n)

> Language: English | [中文](./i18n-ZH.md)

## Supported languages

### Tier-1 (quality bar — full native catalogs)

| Code | Notes |
|------|--------|
| **zh-HK** | Default UI — Hong Kong written Chinese |
| **zh-CN** | Simplified Chinese |
| **en** | English (key SSOT for multi-locale expansion) |

### Tier-2 (world languages — full key catalogs)

| Code | Notes | Direction |
|------|--------|-----------|
| **ja** | Japanese | LTR |
| **ko** | Korean | LTR |
| **hi** | Hindi | LTR |
| **es** | Spanish | LTR |
| **ar** | Arabic | **RTL** |
| **fr** | French | LTR |
| **bn** | Bengali | LTR |
| **pt** | Portuguese | LTR |
| **id** | Indonesian | LTR |
| **ur** | Urdu | **RTL** |

All locales share the same key tree (SSOT = `en`). After large EN edits, fill leftover English leaves with `python3 scripts/i18n-fill-still-en.py` (existing translations are kept). Product names stay English. **Do not** machine-translate zh-HK (that path uses zh-TW).

`zh-TW` / bare `zh` normalize to `zh-HK`. Legacy `in` (Indonesian) → `id`.  
Registry: `packages/shared/locales/locales.json` and `packages/shared/src/i18n/normalize-locale.ts`.

## Source of truth

```
packages/shared/locales/{locale}/{namespace}.json
packages/shared/locales/locales.json          ← locale list + RTL + labels
```

Web: `t()` via react-i18next (`apps/web/src/shared/lib/i18n.ts`).  
Backend: `tl()` / `t(locale, key)`. CLI: `--locale` / `YSK_LOCALE`.  
RTL: `isRtlLocale()` sets `<html dir="rtl" lang="…">` for `ar` and `ur`.

About-tab guides: every shipped locale has `apps/web/src/shared/guides/data/{locale}.json` (13 files). `i18n:check-guides` checks id/structure for all of them. CLI hints (`ysk-server …`) stay English.

## Developer workflow

1. **Tier-1 quality bar:** edit zh-HK / zh-CN / en namespaces in parallel.  
2. Prefer semantic keys; write zh-HK first, then zh-CN and en.  
3. After large EN edits, fill remaining English leaves with `python3 scripts/i18n-fill-still-en.py` (does not overwrite existing translations). **Do not** machine-translate zh-HK (the MT map uses zh-TW and would write Taiwan wording).  
4. Product names stay English (`pnpm i18n:check-brand`).  
5. `pnpm i18n:rebuild`  
6. `pnpm i18n:check-keys && pnpm i18n:check-glossary && pnpm i18n:check-brand && pnpm i18n:check-ui && pnpm i18n:check-api && pnpm i18n:check-drift && pnpm i18n:check-guides`

## Gates

| Script | Role |
|--------|------|
| `i18n:check-keys` | Key sets match **all** locale dirs (SSOT = en) |
| `i18n:check-ui` | No hardcoded CJK in web sources |
| `i18n:check-api` | No hardcoded CJK operator strings in core/server |
| `i18n:check-glossary` | zh-HK forbidden TW/CN terms + spoken Cantonese |
| `i18n:check-drift` | translation.json must match namespace JSON (every locale) |
| `i18n:check-brand` | Product / company names stay English in every locale |
| `i18n:check-guides` | About-tab catalogs aligned for all 13 locales |
