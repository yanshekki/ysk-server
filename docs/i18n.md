# Internationalization (i18n)

> Language: English | [中文](./i18n-ZH.md)

支援語言

| Code | 名稱 | 說明 |
|------|------|------|
| **zh-HK** | 繁體中文 | **預設** · **香港書面語**（繁體字 + 港式書面詞彙） |
| **zh-CN** | 简体中文 | 规范简体 |
| **en** | English | UI + API |

相容：`zh-TW` / bare `zh` → normalize 為 `zh-HK`。

## 香港書面語用詞（繁體）

優先使用：

| 用 | 避免（若語境相同） |
|----|-------------------|
| 軟件 | 軟體 |
| 網絡 | 網路 |
| 電郵 | 郵件（可用於產品域「郵件伺服器」） |
| 檔案 | 文件（簡體用「文件」） |
| 伺服器 | 服務器（簡） |
| 磁碟 | 磁盤 |
| 設定 | 設置（簡） |
| 用戶 | 使用者（可用於少數 UI） |
| 資料庫 | 數據庫（簡） |
| 重新整理 | 刷新（簡） |
| 備份 | — |

語氣：給操作員看的短句；不叫用戶去 terminal 執行指令。

## 文案來源

```
packages/shared/locales/
  zh-HK/translation.json   # 及 common.json、nav.json…
  zh-CN/…
  en/…
```

- **唯一真相**：shared locales JSON  
- **前後端**：`import { t, normalizeLocale } from '@ysk/shared'`  
- **Web UI**：react-i18next，catalog 從 shared 載入（`apps/web/src/shared/lib/i18n.ts`）

## Key 命名

```
common.cancel
nav.protection
roles.admin
errors.YSK_NOT_FOUND
ops.blocked.need_execute
pages.cdn.emptyTitle
```

- 點號分層；**key 內禁止中文**  
- 插值：`{{name}}`（shared `t` 與 i18next 一致）

## 開發流程

1. 在 **zh-HK** 寫香港書面語  
2. 同步 **en** 與 **zh-CN**  
3. 代碼只寫 `t('key')` / `t(locale, 'key')`  
4. `pnpm i18n:check-keys` 確認三語 key 齊全  

```bash
pnpm i18n:check-keys
pnpm --filter @ysk/shared test
```

### 開發：新增文案

1. 編輯 `packages/shared/locales/{zh-HK,zh-CN,en}/<ns>.json`（**先寫 zh-HK 香港書面語**，再 zh-CN、en）  
2. `pnpm i18n:rebuild`  
3. `pnpm i18n:check-keys && pnpm i18n:check-glossary`  
4. Web：`t('ns.key')` · 後端：`tl('ns.key')` / `t(locale, 'ns.key')` / `yskError(code, { messageKey })`  
5. **禁止**在 ts/tsx 寫操作員可見中英業務句（品牌名／技術 ID／日誌原文除外）
