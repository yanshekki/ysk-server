# Feature single entry

> Language: English | [中文](./feature-single-entry-ZH.md)

## Principle

Each product capability has **one** primary sidebar/route entry so operators are not lost in duplicate security/system menus.

## Examples

| Domain | Primary entry |
|--------|----------------|
| Host defense | `/protection` |
| Account security | `/security` (tabs for auth/SSH/2FA) |
| Sites | `/projects` |
