# 功能單入口

> 語言：中文 | [English](./feature-single-entry.md)

## 原則

每個產品能力在側欄／路由只有**一個**主入口，避免重複「安全」「系統」分叉令操作員迷失。

## 例子

| 域 | 主入口 |
|----|--------|
| 主機防護 | `/protection` |
| 帳號安全 | `/security`（認證／SSH／2FA 分 tab） |
| 站點 | `/projects` |
