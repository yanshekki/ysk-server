# VPN（伺服器 + 客戶端）

> 語言：繁體中文（香港書面語）| [English](./vpn.md)

## 用途

在控制面主機管理 **開源 VPN**：

- **伺服器** — 本機接受 WireGuard 客戶端（手機、筆電、其他伺服器）
- **客戶端** — 本機匯入 conf **連出**到其他 VPN

## 引擎

| 引擎 | 狀態 |
|------|------|
| WireGuard | 伺服器 + 客戶端完整 |
| OpenVPN | 伺服器 + 客戶端完整（PKI、`.ovpn`） |
| Shadowsocks（`ss-server`） | 伺服器 + `ss://` 金鑰／QR（非完整 Outline Manager） |

## 路由

| 項目 | 值 |
|------|-----|
| UI | `/vpn` |
| API | `/api/v1/vpn/*` |
| 能力 | `network.vpn` |
| 安裝 | 軟件目錄 `wireguard`／`openvpn`（需 `YSK_EXECUTE` + root） |

## 伺服器流程

1. 安裝分頁 → WireGuard／OpenVPN／Shadowsocks  
2. 伺服器分頁 → 監聽埠 + **公開端點**（QR／下載用；須與防火牆一致）  
3. **連線模式**（每個伺服器設定）：
   | 模式 | 客戶端流量 | 伺服器 NAT（MASQUERADE） |
   |------|------------|-------------------------|
   | **full** | 經 VPN 上網 | 是 |
   | **lan** | 僅 VPN 網段 + 設定的內網 CIDR | 否 |
   | **custom** | 自訂 CIDR 列表 | 僅當列表含預設路由時 |
4. 啟動伺服器 → 開防火牆  
5. 建立客戶端 → **下載金鑰**／**QR Code**

## 客戶端流程（本機連出）

1. 貼上 conf → 匯入  
2. 連線／斷線  
3. **全隧道保護**：若 conf 為全隧道，面板會注入 **來源位址策略路由**，令本機公網 IP 的回應仍走主表 — 面板／SSH 可達，同時連出流量可走隧道。

## 誠實原則

未開 `YSK_EXECUTE` 時，安裝與伺服器／客戶端連線均 **阻擋**（不建半成品）。
