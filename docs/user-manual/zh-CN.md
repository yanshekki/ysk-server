# YSK Server 用户手册（简体中文）

## 安装

```bash
curl -fsSL https://raw.githubusercontent.com/yanshekki/ysk-server/main/install.sh | bash
ysk-server setup
ysk-server serve
```

## Web UI

默认开发账号（生产环境请立即修改）：`admin` / `admin`。

界面语言：繁中、English、简体中文。

## 功能概览

- 仪表盘健康与保护模式
- 项目级 Linux 用户隔离
- 安全：Allowlist、审批、RBAC
- 邮件服务器 + 外部待办
- 智能更新
- AI Agent 运行时
