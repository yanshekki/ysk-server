# YSK Server User Manual (English)

## Install

```bash
curl -fsSL https://raw.githubusercontent.com/yanshekki/ysk-server/main/install.sh | bash
ysk-server setup
ysk-server serve
```

## Web UI

Default bootstrap credentials (change immediately): `admin` / `admin`.

Languages: Traditional Chinese (default), English, Simplified Chinese.

## Features

- Dashboard health & protection mode
- Project isolation (per-site Linux users)
- Security: Allowlist, approvals, RBAC
- Email server + external checklist
- Intelligent updates
- AI agent runtimes
